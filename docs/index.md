# mcp-state Documentation

Welcome to the documentation for **mcp-state**, a Model Context Protocol (MCP) server that implements a "blackboard" pattern for agent state management.

This documentation is structured following the [Diataxis](https://diataxis.fr/) framework, dividing content by user needs:

## [Tutorials](tutorials/getting-started.md)
*Learning-oriented* — Step-by-step guides to get you started with running and interacting with the `mcp-state` server. Start here if you're new to the project.

## [How-to Guides](how-to/manage-agent-state.md)
*Goal-oriented* — Practical, recipe-like guides that help you solve specific problems or achieve specific tasks, such as managing session state and archiving data.

- [Manage Agent State](how-to/manage-agent-state.md)
- [Agent Directives (Stigmergy Protocol)](how-to/agent-directives.md)

## [Reference](reference/mcp-tools.md)
*Information-oriented* — Detailed technical descriptions of the MCP tools provided by the server, including input schemas, errors, and database structures.

## [Explanation](explanation/architecture.md)
*Understanding-oriented* — High-level discussions of the design concepts, the blackboard pattern, and why certain architectural decisions were made.
