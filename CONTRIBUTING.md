# Contributing to mcp-state

First off, thank you for considering contributing to `mcp-state`! We welcome contributions from everyone, whether it's bug reports, feature requests, documentation improvements, or code contributions.

## How to Contribute

1. **Report a Bug**: If you find a bug, please open an issue on GitHub with a clear description, reproduction steps, and expected behavior.
2. **Suggest a Feature**: Have an idea? Open an issue and label it as an enhancement. Describe the motivation and how it benefits the project.
3. **Submit a Pull Request**:
   - Fork the repository.
   - Create a new branch (`git checkout -b feature/my-new-feature`).
   - Make your changes. Ensure code is formatted (`cargo fmt`) and passes linting (`cargo clippy`).
   - Write tests for your changes if applicable.
   - Run the test suite (`cargo test`).
   - Commit your changes (`git commit -am 'Add some feature'`).
   - Push to the branch (`git push origin feature/my-new-feature`).
   - Open a Pull Request on GitHub.

## Development Setup

1. Install [Rust](https://rustup.rs/).
2. Clone the repository: `git clone https://github.com/JohnnytheShark/mcp-state.git`
3. Build the project: `cargo build`
4. Run tests: `cargo test`
